# 인연 · 유튜브 댓글 에이전트 — 디자인 프로토타입 소스

| 파일 | 화면 |
| --- | --- |
| Main.dc.html | 대시보드 (주제 사이드바, ①②③, 게시 기록) |
| Drafts.dc.html | 초안 목록 + 오른쪽 상세 패널 |
| Accounts.dc.html | 계정 관리 (크롬 프로필 등록) |
| NewTopic.dc.html | 새 주제 만들기 |
| States.dc.html | 상태 모음 (실패, 상한, 검사 미통과 등) |
| canvas.json | 캔버스 배치 정보 |
| ds/inyeon/ | 화면이 불러오는 Inyeon 디자인 시스템 사본 |

`.dc.html` 파일은 Claude Design 캔버스 런타임(support.js)에서 돌아가는 형식이에요.
화면을 보거나 눌러보려면 캔버스 링크를 쓰고, 이미지·PDF가 필요하면 캔버스의 내보내기 메뉴를 쓰세요.
실제 앱을 만들 때는 이 파일들을 화면 설계와 상태 로직의 참고 자료로 쓰면 돼요.
