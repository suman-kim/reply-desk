# TopicItem

주제 사이드바의 홍보 대상 하나예요. 이름, 오늘 숫자, 진행 여부를 보여줘요.

- 사이드바는 `surface-sunken` 회색 판(모서리 `radius-xl`)이고, 항목은 그 위에 놓여요. 선택된 항목은 흰 조각으로 떠올라요(`shadow-card`).
- `meta`에는 숫자만 써요. 예: "오늘 1/5 · 초안 4".
- `status="paused"`면 점이 회색이 돼요. 클릭은 그대로 할 수 있어요.
- `count`(파란 숫자)는 대기 중인 초안 수예요. 0이면 숨겨요.
- 목록 끝에는 `dashed` 버튼 "+ 새 주제"를 둬요.
