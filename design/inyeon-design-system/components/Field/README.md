# Field

라벨이 붙은 입력창이나 여러 줄 입력창이에요. 글자 수, 안내, 오류, 옆 버튼을 붙일 수 있어요.

- 입력창은 테두리 없이 옅은 회색으로 채워져 있고, 누르면 흰 바탕에 파란 테두리로 바뀌어요.
- `counter`는 라벨 오른쪽에 고정폭 글꼴로 보여줘요. 예: "91 / 120자". 허용 범위를 벗어나면 `counterInvalid`를 켜요.
- `action`은 입력창 옆에 보조 버튼을 붙여요. 예: "추가".
- `error`는 `hint` 자리를 대신하고 테두리를 `danger-ink`로 바꿔요. 다음에 할 일을 같이 써요.
- `onChange`가 없으면 value는 처음 값으로만 쓰여요.
