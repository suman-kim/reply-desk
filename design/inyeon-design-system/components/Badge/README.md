# Badge

영상·주제·기록 옆에 붙는 한두 단어 상태예요. 색마다 뜻이 정해져 있어요.

| tone | 뜻 | 예 |
| --- | --- | --- |
| neutral | 대기, 판단 없음, 키워드 | 대기, 연애 |
| accent | 다음 단계 준비됨 | 초안 준비됨 |
| rose | 내 채널 (사람 쪽 이야기) | 내 채널 |
| success | 끝나고 확인됨 | 성공, 댓글 완료 |
| danger | 실패 | 실패 |
| warning | 상한 임박, 일시정지 | 일시정지 |

`loading`은 진행 중인 일 앞에 작은 스피너를 붙여요. 예: "초안 작성 중". `dot`은 상태 점을 붙여요. 배지를 버튼처럼 쓰지 않아요.
