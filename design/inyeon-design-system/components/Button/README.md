# Button

동작을 시작하는 버튼이에요. 파란 **primary**는 패널마다 그 패널의 목적 하나에만 써요.

- `primary` (일렉트릭 블루): 패널마다 하나까지. 예: [영상 불러오기], [댓글 달기].
- `dark` (잉크): primary와 나란히 놓일 때 구분이 필요한 두 번째 강한 동작. 예: [샘플 초안 만들기], [주제 저장].
- `secondary` (옅은 회색 면, 테두리 없음): 나머지 전부. 예: [추가], [다시 생성], [주제 설정].
- `ghost`: 빽빽한 곳의 가벼운 동작. 예: 취소.
- `dashed`: 목록에 새 항목 추가. 예: [+ 새 주제].
- `loading`은 색을 유지한 채 스피너를 띄우고 클릭을 막아요. 문구도 진행형으로 바꿔요. 예: "게시 진행 중…".
- 비활성 버튼 아래에는 항상 이유 한 줄을 붙여요.
- 문구는 짧은 동사형으로 써요. "댓글 달기"처럼 쓰고, "댓글을 답니다"처럼 쓰지 않아요.

크기: `sm` 32px(표 안), `md` 44px(기본), `lg` 54px(③의 주요 동작 하나). 링크(`<a>`)를 버튼처럼 보이게 할 때는 `iy-btn iy-btn-<variant> iy-btn-<size>` 클래스를 붙여요.
