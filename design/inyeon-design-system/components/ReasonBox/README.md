# ReasonBox

판단의 이유를 설명하는 색 상자예요. 화면이 결과뿐 아니라 이유까지 보여주게 해요.

| tone | 담는 것 | 라벨 |
| --- | --- | --- |
| accent | 이 영상을 고른 이유 (번호 2~3줄) | 이 영상을 고른 이유 |
| rose | 영상 속 고민, 굵은 한 문장 | 영상 속 고민 한 줄 |
| neutral | 댓글을 이렇게 쓴 이유 | 이 댓글을 이렇게 쓴 이유 |

이유에 들어가는 숫자는 모델이 아니라 코드가 넣어요. 장면은 시점과 함께 인용해요. 예: "05:20". 사람이 초안을 고쳤으면 `note`를 붙여요. 예: "직접 수정한 초안이에요".
