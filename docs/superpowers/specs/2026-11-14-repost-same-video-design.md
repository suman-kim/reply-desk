# 같은 영상에 댓글 더 달기 (RD-27) — 짧은 설계

## 왜
게시를 마친 영상에도 같은 영상에 댓글을 더 달고 싶다. 계정과는 상관없다(같은 계정이어도 된다).
예전 게시 기록은 그대로 남아야 한다.

## 설정으로 켜고 끄기 (2026-11-15 추가, 기본 꺼짐)
과제 문서(track-2)의 운영 규칙 '영상당 댓글 1개·한 영상에는 계정 하나만(코드에서 강제)'과 부딪혀, 이 기능은 설정으로 켜고 끈다.
- 설정 키 `posting.morePerVideo` ('같은 영상에 댓글 더 달기', 설정 → 게시). 공용 설정 표(`app_setting`)의 한 줄이라 DB 구조는 바뀌지 않는다.
- **꺼짐(기본)**: 영상당 1개. 차단 규칙 `already_commented`(이 영상에 성공 기록이 있으면, 주제 상관없이)가 막고,
  이미 단 영상에는 [다시 생성]도 409로 막는다(게시할 수 없어 AI 비용만 든다). 게시 완료는 영상 단위로 센다(`isPosted`).
  게시 완료 화면에는 더 달기 버튼 대신 "영상당 댓글 1개만 달아요 · 설정에서 켜요"와 [설정 열기]를 보인다.
- **켜짐**: 아래 '정한 것'대로 초안 단위. `already_commented`를 건너뛰고 `draft_already_posted`만 본다.
- 어느 쪽이든 DB는 초안마다 성공 1개(`uq_post_attempt_draft_success`)를 막는다. 영상당 1개는 DB가 아니라 차단 규칙(코드)이 지킨다.
  같은 영상 동시 게시는 `uq_post_attempt_video_running`이 그대로 막는다.

## 목표 / 하지 않을 것
- 목표: 게시 완료 영상에서 [새 초안 쓰고 한 번 더 달기] → 새 초안(분석·작성·검사) → [댓글 달기]가 평소처럼 된다.
- 목표: 예전 댓글은 '이 영상의 게시 기록'에 글과 함께 남는다.
- 하지 않을 것: 영상당 댓글 수 상한(방법 B), 유튜브에 단 예전 댓글 지우기.
- 실패로 볼 것: 같은 글이 같은 영상에 두 번 달리는 것.

## 고른 방법: A. 초안 하나에 댓글 하나
| 방법 | 내용 | 고르지 않은 이유 |
|---|---|---|
| **A (고름)** | 게시한 초안은 잠기고, 새 초안을 써서 다시 게시 | — |
| B | A + 주제 설정에 영상당 최대 댓글 수 | 상한을 바라지 않음, 설정이 늘어남 |
| C | 게시 완료를 풀어 같은 초안을 다시 게시 | 같은 글이 두 번 달릴 수 있음 |

## 정한 것 (사용자 승인: 방법 A와 DB 변경)
- **DB**: `post_attempt`의 부분 유일 인덱스 `uq_post_attempt_video_success`(영상마다 성공 1개)를
  `uq_post_attempt_draft_success`(초안마다 성공 1개)로 바꾼다. `uq_post_attempt_video_running`(같은 영상 동시 게시 막기)은 그대로. 컬럼 변경 없음.
- **상태 계산**: '게시 완료'는 "이 영상의 가장 최근 초안(그 주제)에 성공 기록이 있는가"로 센다.
  영상 목록 배지·작업 목록 상태·게시 대기 개수·작업 패널 모두 같다. '실패'도 그 초안의 마지막 시도로 본다.
- **차단 규칙 3번**: 설정을 켜면 `already_commented`(영상당 1개) 대신 `draft_already_posted`("이 초안은 이미 게시했어요 · [새 초안 쓰고 한 번 더 달기]")만 본다.
- **고치기**: 게시한 초안은 서버에서도 고칠 수 없다(409). 설정을 켜면 [다시 생성]으로 새 초안 행이 생긴다(끄면 이미 단 영상은 409).

## 내가 정한 것 (고칠 수 있음)
- 새 초안을 쓸 때 이 영상에 이미 단 댓글(최근 5개, 주제·계정 상관없이)을 프롬프트 끝에 붙여 "겹치지 않게 다른 장면·다른 말로" 쓰게 한다.
  설정에서 고친 프롬프트 틀과 상관없이 코드가 붙인다(다시 쓸 때 덧붙이는 글과 같은 방식).
- 자동 검사에 '이미 단 댓글과 다름'을 더한다. 이미 단 댓글과 글이 같으면(공백 무시) 걸린다. 단 댓글이 없으면 건너뛴다.
- 작업 상세 머리에 "이 영상에 단 댓글 N개"를 보이고, 게시 기록 행마다 단 댓글 글을 보인다.
- 영상 목록 응답에 `commentCount`(이 영상에 단 댓글 수, 주제 상관없이)를 더한다.
