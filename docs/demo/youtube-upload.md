유튜브 댓글 에이전트 시연 · 운명원 연애 사주 (TRACK 2 마케팅 AI 에이전트)

## 설명
영상을 불러오고, 고르고, 버튼 한 번이면 크롬 프로필이 열려 직접 타이핑으로 댓글을 다는 대시보드입니다.

주요 기능
- 계정 연결: 계정마다 전용 크롬 프로필, 로그인·채널·한국어 화면 확인
- 주제: 홍보 대상(운명원)·검색어·기간·순위 기준·댓글 조건·게시 계정·하루 상한
- 영상 불러오기: 썸네일·제목·채널·올린 날짜·조회수, 관련도/조회수/최신 정렬, 링크 직접 추가
- 초안 작성: AI가 영상과 인기 댓글로 주제 매칭과 근거 장면을 찾고, 시청자 고민 한 줄을 꾸며 그 사람처럼 댓글 작성
- 자동 검사: 글자 수·장면 언급·브랜드 한 번·링크/해시태그·지어낸 후기·최근 초안과 겹치는 말버릇
- 댓글 달기: 크롬 프로필로 한 글자씩 입력 → 게시 → 내 댓글 확인, 실패하면 이유와 캡처
- 운영 규칙: 영상당 댓글 1개(기본)·하루 상한을 코드가 강제, 같은 초안 두 번 게시는 DB가 막음, 게시 기록을 시간순으로

제작 의도: 숫자는 코드가, 판단은 AI가, 검증은 다시 코드가 맡는다.
