# 시연 영상 스토리보드 · 내레이션 대본 (RD-34)

- 길이: 약 3분 (과제: 2~3분). 화면 1920×1080, 한국어 자막 + 한국어 음성(맥 TTS).
- 주제: 운명원 연애 사주. 홍보 대상: 운명원 · 연애 사주 잘 보는 곳.
- 기다리는 구간(AI 분석·초안 작성, 영상 불러오기)은 빨리 감기로 줄인다.
- 실제 게시 1회: 크롬 프로필 창이 열리며 한 글자씩 입력 → 게시 → 내 댓글 확인까지 그대로 보인다.
- 비밀번호·2단계 인증은 녹화하지 않는다(로그인은 사용자가 직접, 그 구간은 자르거나 가린다).

## 녹화 순서 (기술)
1. 대시보드 브라우저 창(왼쪽)과 게시용 크롬 창(오른쪽)을 나란히 두고 주 화면 전체를 녹화한다(ffmpeg avfoundation).
2. 장면 시작·끝 시각을 녹화 스크립트가 기록한다 → 장면별로 자르고, 음성 길이에 맞춰 마지막 장면을 늘리거나 기다리는 구간을 빨리 감는다.
3. 자막(AppleSDGothicNeo)과 음성(say)을 입혀 mp4(H.264, AAC)로 만든다.
