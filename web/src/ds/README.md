# Desk — reply-desk 디자인 시스템

2026-11 리디자인(기획 명세 RD-26)에서 새로 만든 시스템입니다. 시안은 Claude Design 캔버스 **reply-desk 리디자인**의 '디자인 시스템' 보드에 있습니다.

## 원칙

- **조용한 바탕, 판단할 것만 또렷하게.** 회색 셸(`--shell`) 위에 흰 작업면(`--ground`) 한 장. 왼쪽 사이드 메뉴는 셸 위에 둡니다.
- **버튼은 잉크색.** 주 동작은 `Button variant="dark"`. 바이올렛(`variant="primary"`)은 화면에 하나, [댓글 달기]처럼 그 화면의 핵심 동작에만 씁니다.
- **포인트 색은 바이올렛 하나**(`--accent`): 선택 · 포커스 · 검색어 표시(`Keyword`) · [댓글 달기].
- **상태 색 규칙 (의미 → 색 하나)**: 성공 초록 · 주의 노랑 · 실패 빨강 · 진행 파랑 · 중립 회색. 색만으로 나누지 않고 `Badge`가 모양(체크 · 세모 · 엑스 · 도는 원 · 점)을 붙입니다.
  - 게시 완료 · 매칭됨 · 로그인됨 → `success`
  - 검사 미통과 · 매칭 낮음 · 로그인 필요 → `warning`
  - 작성 실패 · 게시 실패 → `danger`
  - 작성 중 · 게시 중 → `info` (+ `loading`)
  - 게시 대기 → `neutral` + `dot` (문제가 아니라 할 일이라 중립. 대신 검은 숫자 배지로 눈에 띄게)
- **글자로 위계, 두 가지 밀도.** 목록은 13~14px로 촘촘하게, 상세는 15px · 줄 간격 1.75로 넉넉하게. 시각 · 글자 수 · 조회수 · 주소는 고정폭(`--font-mono`, Geist Mono).
- **그림자는 떠 있는 것만.** 회색 위 흰 조각(선택된 메뉴, 세그먼트)은 `--shadow-card`, 패널 · 알림 · 창은 `--shadow-pop`.
- 모서리: 배지 6 · 버튼과 입력 9 · 카드 12 · 작업면 14. 간격은 4px 격자.

## 부품

| 부품 | 쓰는 곳 |
| --- | --- |
| `Button` | 동작. `dark`(주) · `primary`(바이올렛, 화면에 하나) · `secondary` · `ghost` · `dashed` |
| `Badge` | 상태. `tone` + 자동 모양, `dot`(게시 대기), `loading`(진행) |
| `StatPill` | 숫자 계기 (오늘 전체 게시 3 / 30) |
| `Panel` | 카드 |
| `Field` | 입력 칸 (이름 · 글자 수 · 안내 · 오류) |
| `Segmented` | 여럿 중 하나 (정렬, 계정, 보기 방식) |
| `Tabs` | 밑줄 탭 (긴 화면 나누기, 상태로 나누기) |
| `Chips` | 거르기 칩 |
| `Keyword` | 주제의 검색어 표시 |
| `MatchBar` | 주제와 매칭 % (기준 눈금, 기준 이상 초록 · 미만 노랑) |
| `VideoCard` · `ReasonBox` · `CheckList` · `StepList` · `BrowserFrame` | 영상 · 이유 · 자동 검사 · 게시 단계 · 크롬 미리보기 |

예전 Inyeon과 같은 부품 이름 · props를 지켜, 화면 코드는 `import { … } from '../ds'`만 바꾸면 됩니다.
